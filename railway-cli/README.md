# 🚆 Railway Management CLI (Вариант 48)

Система организации и управления железнодорожным транспортом с интерфейсом командной строки (CLI), реализованная на Python.

## 📋 Предметная область
Модель охватывает основные сущности железнодорожного транспорта и ключевые операции диспетчеризации.

### 🧩 Сущности
- `RailwayTrack` — железнодорожный путь
- `Station` — станция
- `Locomotive` — локомотив
- `Wagon` — вагон
- `Train` — поезд (состав)
- `Schedule` — расписание движения
- `Ticket` — проездной документ

### ⚙️ Операции
| Операция | Описание |
|----------|----------|
| `operation_movement` | Движение поездов с проверкой путей и расписания |
| `operation_station_service` | Обслуживание станций (разгрузка путей, логистика) |
| `operation_maintenance` | Техническое обслуживание подвижного состава и инфраструктуры |
| `operation_ticket_sales` | Продажа билетов с привязкой к расписанию |
| `operation_security_control` | Контроль безопасности перед отправлением |
